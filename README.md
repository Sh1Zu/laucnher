# TheVaultRP Launcher

Официальный лаунчер сервера **The Vault RP**. Ставит игру, нужные моды и подключает к серверу одной кнопкой.

## Скачать

**[Скачать последнюю версию](../../releases/latest)**

Файл `TheVaultRPLauncher-Setup-x.y.z.exe` — обычный установщик. Права администратора не нужны.

Скачивайте **только со страницы релизов этого репозитория**. Файл с таким же именем, полученный откуда-то ещё, может быть чем угодно.

### Проверка файла

Установщик пока не подписан сертификатом, поэтому Windows SmartScreen при первом запуске покажет предупреждение — это ожидаемо. Чтобы убедиться, что файл не подменён, сверьте его контрольную сумму:

```powershell
Get-FileHash TheVaultRPLauncher-Setup-0.4.1.exe -Algorithm SHA256
```

| Версия | SHA-256 |
|---|---|
| 0.4.1 | `151d7ccbe0a1c225af5605041717ba25bab1c820ed0ff5e9eef6a4607dd7427f` |

Если сумма не совпала — файл скачан не отсюда либо повреждён. Не запускайте его.

## Что нужно

- Windows 10 или новее, 64-разрядная
- Около 1.5 ГБ свободного места
- Интернет для первой установки

Ставить .NET, Java или Minecraft заранее **не нужно** — лаунчер разберётся сам. Если в системе не окажется компонента Microsoft Edge WebView2, установщик скачает его автоматически.

## Что делает лаунчер

- Скачивает Minecraft 1.21.8 и загрузчик модов Fabric с официальных источников Mojang и FabricMC.
- Ставит модифицированную облегчённую сборку: голосовой чат Plasmo Voice плюс Sodium и Lithium для FPS.
- Подключает к серверу — адрес вводить не нужно.
- Обновляется сам: при запуске проверяет, не вышла ли новая версия.

Сборка кладётся в отдельную папку `%APPDATA%\.thevaultrp`. **Ваш обычный `.minecraft` не трогается** — миры и другие сборки останутся на месте.

## Вход

Два способа:

- **По лицензии Minecraft** — через учётную запись Microsoft. Пароль вводится только на сайте Microsoft, лаунчер его не видит и не сохраняет.
- **По нику** — если лицензии нет.

Можно завести до трёх персонажей и переключаться между ними.

## Что лаунчер знает о вас

- На диск сохраняются только ник и способ входа, в файле `%APPDATA%\.thevaultrp\launcher.json`.
- Токен доступа Microsoft живёт в памяти до закрытия лаунчера и никуда не записывается.
- Из профиля берутся только ник и UUID.
- Лаунчер обращается только к серверам Mojang, Microsoft, FabricMC, Modrinth и к этому репозиторию за обновлениями. Своей телеметрии у него нет.

## Удаление

Обычным способом — «Установка и удаление программ» или ярлык в меню «Пуск».

Папка со сборкой игры при удалении **остаётся**: там ваши миры, настройки и сохранённые персонажи. Если нужно стереть и её — удалите `%APPDATA%\.thevaultrp` вручную.

## Проблемы

Пишите в Discord сервера. К сообщению приложите файл `%APPDATA%\.thevaultrp\logs\latest.log` — по нему видно, что пошло не так.
